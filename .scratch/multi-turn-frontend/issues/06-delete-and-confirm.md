# 06: 删除会话与二次确认

**What to build:** 用户 hover 或键盘聚焦到真实会话条目时看到小删除按钮；点击后弹出确认框，写明会话标题与「删除后不可恢复」。确认前不发请求。确认后软删该会话：若删的是当前会话且正在流式，先中止请求；删除成功后从列表移除，切到剩余最近会话，列表为空则回到欢迎空态。草稿态永远没有删除入口。

**Blocked by:** 05 切换会话与草稿丢弃

**Status:** ready-for-agent

**后端并行:** 可（mock 提供内存删除与 404；真实删除联调在 P2 完成后）

**范围:** 会话条目 hover 删除、确认弹窗、删除接口、删除后切换、404 幂等、焦点归还

**预估:** 1.5h

- [x] 仅真实会话条目显示删除按钮；hover 与 `focus-within` 都能显示，键盘可聚焦
- [x] 删除按钮有 `aria-label`（含会话标题），且与选择按钮是兄弟节点，不出现按钮嵌套
- [x] 点击删除只打开确认框，确认前没有 `DELETE` 请求发出
- [x] 确认框文案包含会话标题与「删除后不可恢复」；点击取消不改列表，焦点回到触发删除按钮
- [x] 删除当前会话前先中止正在进行的流式请求，已渲染内容不再继续追加
- [x] 删除成功：条目移除；当前会话被删时切到剩余列表首项，列表为空时回到空态
- [x] 删除非当前会话：当前对话与流式状态不受影响
- [x] 删除失败：保留条目与弹窗，弹窗内展示服务端 `msg` 原文，可取消后重试
- [x] 重复删除返回 404：视为已删除，移除本地条目并提示，不显示笼统失败
- [x] 草稿态没有删除入口，且不会发出任何删除请求
