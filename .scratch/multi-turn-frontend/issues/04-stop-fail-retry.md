# 04: 停止、失败、未召回与重试

**What to build:** 用户在生成过程中可以停止，已生成的半截正文保留并标记「已停止」；后端推送 `error` 事件时，本轮保留已到达正文与来源，展示服务端原因并提供「重试」；本轮未召回时不出现 `sources`，按普通提示展示而不是错误。重试是在当前会话发起新一轮，旧轮原样保留。

**Blocked by:** 03 重新打开、历史轮次与多轮追问

**Status:** ready-for-agent

**后端并行:** 可（mock 用关键词模拟空召回与生成失败，停止用 `AbortController` 驱动）

**范围:** 停止、`error` 事件、空召回、轮次级重试、历史失败/停止展示

**预估:** 1.5h

- [ ] 点击停止后 `AbortController.abort()`，本轮状态为 `stopped`，已生成正文与已到达来源保留
- [ ] 停止后输入框恢复可用，可继续提问；停止不算失败，不弹错误
- [ ] 收到 SSE `error` 事件：本轮状态为 `error`，保留半截正文与来源，展示服务端原因 + 「重试」
- [ ] 未收到 `sources` 或 `sourceCount === 0`：展示未召回普通提示，不标记失败
- [ ] 重试在当前会话发起新一轮，旧轮内容与状态不变；新轮使用后端返回的新 `roundId`
- [ ] 流式期间禁止重复提交；停止按钮仅在流式中可用
- [ ] 历史 `FAILED` 轮可重试，历史 `STOPPED` 轮显示「已停止」且正文保留
- [ ] mock 模式可演示停止、空召回、生成失败、重试四种路径
