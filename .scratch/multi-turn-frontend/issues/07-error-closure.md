# 07: 404 / 409 / 网络中断闭环

**What to build:** 补齐会话级错误分支：会话不存在或已删除时移除条目并切走；会话正在生成返回 409 时，把原问题放回输入框并展示服务端原因，不自动重试；网络中断时保留已到达的半截正文与来源，提供重试。400 也回填输入并展示服务端原文。

**Blocked by:** 04 停止、失败、未召回与重试；05 切换会话与草稿丢弃

**Status:** ready-for-agent

**后端并行:** 可（mock 用关键词模拟 404/409；网络中断可用浏览器离线或 mock 抛网络错误）

**范围:** 流建立前错误、流中网络错误、输入恢复、404 移除会话

**预估:** 1.5h

- [ ] 流建立前 404：回滚本轮乐观气泡，从列表移除该会话，提示服务端 `msg`，切到剩余最近会话或空态
- [ ] 404 后不再向该 `conversationId` 发任何请求；刷新列表也不会保留它
- [ ] 流建立前 409：回滚乐观气泡，原问题回到输入框，展示服务端 `msg`，不自动重试
- [ ] 流建立前 400：回滚乐观气泡，原问题回到输入框，展示服务端 `msg`
- [ ] 流建立前 5xx：保留本轮错误气泡，提供手动重试，不丢已输入的问题
- [ ] 流中网络中断：本轮标记错误，保留半截正文与已到达来源，展示连接失败提示 + 重试
- [ ] 草稿首问遇到网络失败：仍保持草稿，列表无新增；重发按首问处理
- [ ] 重试只由用户点击触发；任何错误都不会自动重新发起请求
- [ ] mock 模式能演示 404 与 409；网络中断可通过浏览器离线验证
